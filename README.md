# 项目拷问官

面向技术岗项目深挖的训练器。用户输入简历项目和技术方向后，系统会生成项目事实卡、连续追问、即时诊断和抗拷问报告。

## 产品定位

它不是通用 AI 面试官，也不对准某个公司。它只解决一个窄问题：

> 技术岗同学的简历项目，能不能扛住真实面试官连续追问？

## 当前功能

- 项目材料输入：技术方向、面试强度、岗位关键词、项目描述、重点追问方向
- 项目事实卡：识别个人贡献、指标、数据来源、工程落地和初始风险点
- 连续追问：覆盖真实性、方法选择、技术细节、指标评估、工程落地、失败案例、伪代码和前沿理解
- 即时诊断：指出回答哪里虚、哪里缺指标、哪里像调包、下一步可能被追哪里
- 抗拷问报告：生成总分、危险追问点、下一轮训练重点和项目表达模板

## 运行方式

这是一个静态网页，直接打开 `index.html` 即可使用。

也可以在本目录启动本地服务：

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

## 后续可接入大模型

当前版本使用本地规则引擎，保证无 API key 也能跑通完整闭环。后续可以把以下部分替换为 LLM 调用：

- `buildQuestions`：根据项目材料生成更贴近真实面试官的追问
- `diagnoseAnswer`：对回答做更细的语义诊断
- `renderReport`：生成更自然的复盘报告

前端交互和数据结构已经按这个方向设计。
