# 案例 01：智能代码评审助手

推荐技术方向：软件工程 / 代码项目

岗位关键词：代码质量、AI 评审、AST、规则引擎、测试覆盖、误报漏报

重点追问方向：代码实现、指标设计、工程落地、行业趋势

## 项目描述

智能代码评审助手。用户提交一段 Python 或 JavaScript 代码后，系统会解析代码结构，识别潜在 bug、复杂度过高的函数、缺失的异常处理和测试薄弱点，并生成修改建议。我负责核心分析链路、规则引擎、AI 评审提示词、前后端接口和评估集构建。技术栈包括 Python、FastAPI、AST 解析、规则检查、AI API 和简单前端页面。我用 80 个真实开源 issue 和人工构造样例做了初步评估，记录了误报率、漏报率和平均响应耗时。目前 demo 已能运行，但对复杂跨文件调用、第三方库语义和企业代码安全边界处理还不完整。

## 弱回答测试

这个项目主要就是调用 AI 帮用户检查代码，然后返回建议。效果还不错，能发现一些 bug。

## 强回答测试

我负责核心分析链路。输入代码后，我先按语言选择解析器，Python 用 ast 模块抽取函数、调用、异常处理和复杂度特征，JavaScript 先做了简化的正则和语法结构提取。规则引擎会先跑确定性检查，例如空 except、过长函数、未处理 promise，再把代码片段和规则结果一起交给 AI 做解释和建议生成。评估上我做了 80 个样例，按“应报问题”和“不应报问题”统计误报率、漏报率和平均耗时。现在最大问题是跨文件语义不完整，所以企业落地时需要先限制在单文件 review 或接入代码索引服务。
