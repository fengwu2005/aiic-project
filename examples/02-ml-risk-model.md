# 案例 04：交易风险识别模型

推荐技术方向：算法 / 机器学习

岗位关键词：分类模型、特征工程、损失函数、AUC、召回率、误报率

重点追问方向：数据来源、标签质量、baseline、指标设计、线上线下 gap

## 项目描述

交易风险识别模型。项目目标是识别异常交易，降低欺诈损失。我负责特征工程、模型训练、阈值选择和误判分析。数据来自脱敏历史交易日志，包括交易金额、时间、设备、账户行为、地理位置变化和历史风险标记。模型使用 LightGBM 作为主模型，并和逻辑回归 baseline 对比。评价指标包括 AUC、召回率、误报率和高风险队列人工审核通过率。我发现单纯追求 AUC 会导致高金额小样本风险识别不足，因此单独分析了高金额交易分层指标。当前问题是标签有延迟，且线上分布会随业务活动变化。

## 弱回答测试

我用了 LightGBM 做风险识别，AUC 提升了，效果比传统方法更好。

## 强回答测试

我先做了逻辑回归 baseline，再上 LightGBM。特征包括账户历史行为、设备变化、地理位置跳变和交易金额分桶。指标不只看 AUC，因为业务更关心高风险交易召回和人工审核成本，所以我同时看召回率、误报率和高金额分层表现。阈值不是固定选最高 F1，而是根据人工审核容量和风险损失做折中。最大风险是标签延迟和业务活动造成分布偏移，所以需要按周监控特征分布和坏样本召回。
