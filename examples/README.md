# 测试案例

这些案例用于测试“项目拷问官”的几个经典技术方向。每个文件都包含：

- 推荐技术方向
- 岗位关键词
- 重点追问方向
- 可复制的项目描述
- 建议测试回答

建议测试方式：

1. 打开页面。
2. 选择案例里的推荐技术方向。
3. 复制“项目描述”到输入框。
4. 点击“开始拷问”。
5. 用“建议测试回答”里的弱回答和强回答分别测试诊断效果。

案例列表：

- `01-code-review-assistant.md`：软件工程 / 代码项目
- `02-ml-risk-model.md`：算法 / 机器学习
- `03-backend-order-system.md`：后端 / 工程系统
- `04-robotics-vlm-training.md`：Robotics / VLM 大模型训练
